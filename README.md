# 온라인 키캡 토이

스트레스를 풀어주는 귀여운 온라인 키캡 클릭 장난감입니다. React(Vite)와 Supabase를 기반으로 개발하며, 다양한 캐릭터와 스위치음을 통해 가볍게 즐길 수 있는 웹 서비스를 제공합니다.

## 주요 기능

### 1. 자유모드

- 키캡을 자유롭게 클릭하며 즐기는 모드
- 손그림 스타일의 캐릭터 12종 제공
- 취향에 따라 4종의 스위치음 선택 가능

### 2. 타임어택

- 제한 시간 10초 동안 최대한 많은 키캡을 눌러 점수 획득
- 게임 시작 전 3-2-1 카운트다운 제공
- 종료 직전 3초 동안 화면 흔들림과 펄스 효과로 긴장감 연출
- 점수 랭킹을 통한 기록 경쟁

### 3. 포토 키캡 (서포터 전용)

- 사진을 손그림 라인아트 캐릭터로 변환하여 키캡에 적용
- 여러 사진을 등록하고 캐릭터 목록에 저장하여 자유롭게 선택
- Canvas 2D를 활용해 브라우저에서 이미지 변환 처리
- 서버 업로드 및 외부 AI API 호출 없이 작동하여 개인정보 보호와 비용 절감

### 4. 스위치 선택

- 서포터 여부와 관계없이 모든 사용자가 동일하게 스위치 종류와 소리를 선택 가능

## 서포터 시스템

- Supabase의 `redeem_codes` 테이블과 `redeem_code()` Security Definer 함수를 이용한 1회용 후원 코드 검증
- 코드 등록 시 닉네임이 사이트 내 창립 후원자 명단에 공개
- 타임어택 랭킹에서 후원자를 👑 아이콘으로 표시

## 기술 스택

- **Frontend:** React, Vite
- **Backend / Database:** Supabase
- **Image Processing:** Canvas 2D
- **Database Schema:** `supabase/schema.sql`

## 로컬 실행 방법

```bash
npm install
npm run dev
```

실행 후 터미널에 표시되는 로컬 주소로 접속하면 서비스를 테스트할 수 있습니다.
